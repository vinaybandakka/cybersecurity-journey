# Day 37: MITRE ATT&CK

**Phase 6: Offensive security and vulnerability management** · Area: Offensive · Planned: 2026-12-15 · Time: 45 min

## Outcome

By the end of today you can: Navigate ATT&CK, map a real intrusion to techniques, and use it to find detection gaps.

## 1. Learn (15 min)

- [MITRE ATT&CK](https://attack.mitre.org/)
- [ATT&CK Navigator](https://mitre-attack.github.io/attack-navigator/)

## 2. Lab (25 min)

- [ ] Pick a public incident report (for example a CISA advisory) and list the techniques used with their T-IDs.
- [ ] Create a Navigator layer, colour those techniques and export the JSON into labs/attack/.
- [ ] Mark which ones you could detect with logs you have seen so far.

## 3. Explain it like an SME (5 min)

> How would you use ATT&CK to tell a CISO where the detection gaps are?

Answer out loud first, then write a 3 to 5 sentence answer in your notes.

## Deliverable

- [ ] Commit: `labs/attack/<incident>-layer.json and notes/day-37.md`
- [ ] Update the Notion tracker row for Day 37 (Status, Confidence 1-5, Minutes, Notes)
