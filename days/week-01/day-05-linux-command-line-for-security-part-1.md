# Day 05: Linux command line for security, part 1

**Phase 1: Foundations and home lab** · Area: Foundations · Planned: 2026-11-13 · Time: 45 min

## Outcome

By the end of today you can: Move around Linux, read files in awkward ways, and use ssh comfortably under pressure.

## 1. Learn (15 min)

- [OverTheWire Bandit wargame](https://overthewire.org/wargames/bandit/)
- ▶️ [NetworkChuck, Linux for Hackers (YouTube playlist): first two episodes](https://www.youtube.com/playlist?list=PLIhvC56v63IJIujb5cyE13oLuyORZpdkL)

## 2. Lab (25 min)

- [ ] Play Bandit levels 0 to 6.
- [ ] For each level, record the command that solved it and the concept (hidden files, spaces in names, file types).
- [ ] Never store the passwords themselves in the repo; store the technique.

## 3. Explain it like an SME (5 min)

> How would you find every file on a server owned by user X, of size 33 bytes, that is not executable?

Answer out loud first, then write a 3 to 5 sentence answer in your notes.

## Deliverable

- [ ] Commit: `labs/writeups/bandit.md (levels 0-6).`
- [ ] Update the Notion tracker row for Day 05 (Status, Confidence 1-5, Minutes, Notes)
