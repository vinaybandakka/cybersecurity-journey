# Day 03: Security frameworks, NIST CSF 2.0 and CIS Controls

**Phase 1: Foundations and home lab** · Area: Foundations · Planned: 2026-11-11 · Time: 45 min

## Outcome

By the end of today you can: Name the six NIST CSF 2.0 functions and explain how CIS Controls and ISO 27001 relate to it.

## 1. Learn (15 min)

- [NIST Cybersecurity Framework home](https://www.nist.gov/cyberframework)
- [CIS Critical Security Controls](https://www.cisecurity.org/controls)
- [ISO/IEC 27001 overview](https://www.iso.org/standard/27001)

## 2. Lab (25 min)

- [ ] Draw a table with the six CSF functions (Govern, Identify, Protect, Detect, Respond, Recover).
- [ ] Map at least two things you did in DevOps to each function (for example backups map to Recover, alerting to Detect).
- [ ] Mark the function where your last team was weakest and write why.

## 3. Explain it like an SME (5 min)

> An executive asks which framework you would use for a 200-person SaaS startup and why. Answer in 90 seconds.

Answer out loud first, then write a 3 to 5 sentence answer in your notes.

- [ ] Commit: `notes/day-03.md with your CSF mapping.`
