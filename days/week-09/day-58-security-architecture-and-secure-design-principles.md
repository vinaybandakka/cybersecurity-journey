# Day 58: Security architecture and secure design principles

**Phase 9: GRC, architecture and capstone** · Area: Architecture · Planned: 2027-01-05 · Time: 45 min

## Outcome

By the end of today you can: Design a secure cloud architecture using defence in depth and secure design principles.

## 1. Learn (15 min)

- [AWS Well-Architected Framework: Security pillar](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/welcome.html)
- [OWASP Secure Product Design Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Secure_Product_Design_Cheat_Sheet.html)

## 2. Lab (25 min)

- [ ] Design a 3-tier web app on AWS (or your cloud) and draw it.
- [ ] Annotate identity, network, data protection, logging/detection and incident response controls.
- [ ] Note which design principle (least privilege, fail secure, defence in depth, separation of duties) each control follows.

## 3. Explain it like an SME (5 min)

> Defend your architecture against a reviewer who asks 'what happens if the web tier is compromised?'

Answer out loud first, then write a 3 to 5 sentence answer in your notes.
